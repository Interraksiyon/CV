## About this repository

The résumé is maintained in [index.html](index.html), with its visual design,
styles, and interactions in a single file. GitHub Pages serves the published
version at **https://interraksiyon.github.io/CV/**.

## Preview and update

- To preview the résumé, open `index.html` in a web browser.
- To update it, edit or replace `index.html` and commit the change to `main`.
  GitHub Pages rebuilds the published résumé automatically.
- Check the [deployment status](https://github.com/Interraksiyon/CV/actions)
  after publishing.

No build tools or package installation are required. The page loads Tailwind CSS
and Google Fonts online, so a network connection is needed for its full styling.
